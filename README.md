# Sales-Dashboard
## Project Overview

This project is an interactive Sales Insights Dashboard developed using Power BI.

The dashboard analyzes sales performance across different markets, customers, and products to help business stakeholders make data-driven decisions.

The project includes data modeling, Power Query transformations, DAX measures, and interactive visualizations.

---

## Tools Used

- Power BI Desktop
- MySQL Database (Imported using ODBC)
- DAX
- Power Query
- GitHub

---

## Dashboard Features

- Revenue KPI
- Sales Quantity KPI
- Revenue Trend Analysis
- Top 5 Customers
- Top 5 Products
- Revenue by Markets
- Sales Quantity by Customers
- Interactive Year and Month Filters

---

## Data Model

The project follows a Star Schema.

Fact Table

- Transactions

Dimension Tables

- Customers
- Products
- Markets
- Date

---

## Key Insights

- Identified top-performing customers.
- Analyzed monthly revenue trends.
- Compared revenue across different markets.
- Identified best-selling products.
